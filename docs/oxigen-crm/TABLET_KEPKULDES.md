# Tablet -> CRM kepkuldes (Megosztas gomb)

Egyszeri beallitas a tableten (Samsung / Android, Chrome):
1. Chrome: www.mosaicheadspa.hu/crm, belepes a sajat e-mail-cimmel (6 jegyu kod).
2. Chrome menu (harom pont) -> "Telepites" / "Alkalmazas telepitese" (vagy "Hozzaadas a kezdokepernyohoz") -> Telepites. Megjelenik a MOSAIC CRM ikon.

Minden kepnel:
1. A hajkamera-appban elkeszul a kep (a Galeriaba kerul).
2. Galeria -> a kep megnyitasa -> Megosztas -> MOSAIC CRM.
3. A CRM megnyilik, es a kep magatol elkuldodik a Kep-beerkezobe (nem kell vendeget megadni).
4. A kezelo a telefonon: Kezeles kozben -> a vendeg -> 2. lepes -> Beerkezett kepek -> a kep -> Igen, ehhez a vendeghez.

Tudnivalok:
- A hozza nem rendelt kep 6 ora mulva automatikusan torlodik.
- A feltoltes idejere a tabletnek internet kell (mobiladat, vagy a szalon Wi-Fi-je; a kamera sajat Wi-Fi-jen nincs internet).
- Ha a MOSAIC CRM nem jelenik meg a Megosztas listaban: telepitsd ujra a Chrome menubol, majd probald ujra. iPhone-on a Megosztas-celpont nem tamogatott (a kepet a Kepkuldes menu gombjaval kell kivalasztani).
- Technikai: pwa-crm/crm.webmanifest (share_target), pwa-crm/crm-sw.js, assets/js/crm-megosztas.js.
